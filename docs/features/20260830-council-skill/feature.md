# Council skill

## Goal

Stress-test an important engineering decision through independent advice, anonymous peer review and one final verdict.

## Acceptance criteria

- **AC1** – five defined advisors receive the same neutral evidence pack
- **AC2** – peer reviewers compare anonymous responses and identify missed risks or assumptions
- **AC3** – the result gives one recommendation, its reason and the first action

## Boundaries

- Use the council for expensive decisions, not simple facts or mechanical changes
- Explicit invocation authorizes subagents only for that council session
- Use a disclosed same-conversation fallback when delegation is unavailable
- Keep the verdict in the conversation unless the user asks to save it
